# Einherjar Chest

A shared hoard for your Viking fellowship. A mystery waiting in the tenth realm.

There is more to these old stones than trophies and forgotten victories. Listen to Hugin, gather your companions, and discover what Oden has in store.

Einherjar Chest brings shared supplies to your adventures, crafting and homestead. The rest is yours to discover in-game. **Enable Tutorials in Valheim's settings and listen to Hugin to get started.** Solo Vikings are welcome too.

## Installation

Requires **Valheim and BepInEx 5**. Install the same version on **the server and every client**, including the host. No Jotunn or SQLite runtime is required.

1. Close the game/server and back up your world, characters and mod saves.
2. Install **EinherjarChest** through your mod manager, or copy `plugins/SharedInventory.dll` from the ZIP into `BepInEx/plugins/EinherjarChest/`.
3. Keep only one copy of `SharedInventory.dll` in the plugins tree, then start the game.

**Coming from Thor's Kist?** Remove that package on every peer first, including earlier Einherjar Chest releases distributed under the `ThorsKist` package name. Existing Einherjar Chest save/config paths are preserved. Original Thor's Kist data is not automatically imported. See the [installation and migration details](https://github.com/sudonym1/kist/blob/main/GUIDE.md#installation-and-replacing-thors-kist) before switching.
